Kenapa "render per frame" itu penting?

Rekam layar bergantung pada kecepatan laptop: kalau laptop sibuk, video patah-patah. Di cara ini, animasi dibuat deterministik: gambar di detik 3,25 selalu sama persis, secepat atau selambat apa pun komputernya. Hasilnya mulus seperti render After Effects.

const DURATION = 15; // panjang video (detik) function renderAt(t) { // gambar frame di detik ke-t const masuk = easeOut(clamp((t - 0.5) / 0.6)); // judul masuk 0,5–1,1 dtk judul.style.transform = `translateY(${(1 - masuk) * 80}px)`; ... } window.renderAt = renderAt; window.DURATION = DURATION; // dipakai mesin render

Motion blur asli

Tiap frame adalah rata-rata 6 potret kecil, jadi gerakan cepat terlihat "ngeblur" natural.

Suara tersinkron

Efek suara dibuat oleh skrip Python dan ditaruh tepat di detik tiap gerakan.

Bisa diulang

Ganti teks atau warna, render ulang, hasilnya konsisten. Cocok untuk jasa.

Cloud atau lokal?Dua-duanya bisa.

Claude Code-nya sama. Bedanya hanya di mana komputernya berjalan: di server Anthropic (cloud) atau di laptopmu sendiri (lokal).

Jalur A · Cloud

claude.ai/code

  • Tanpa instal apa pun, jalan di browser atau HP
  • Tetap jalan walau laptop ditutup
  • Butuh repo GitHub
  • File hasil diambil dari GitHub

Desktop app / terminal

  • File langsung ada di laptopmu
  • Tidak wajib pakai GitHub
  • Perlu instal Node.js, ffmpeg, Chromium
  • Render memakai tenaga laptopmu

Cocok untuk: sering render, file besar, klien banyak.

Simpan branddi satu folder.

Rahasia kenapa semua video kami seragam: Claude selalu membaca folder brand yang sama sebelum bekerja. Buat foldernya sekali, pakai selamanya.

otakrental-brand/ ├─ CLAUDE.md ← aturan brand ├─ assets/ │ ├─ logo.png │ └─ logo-putih.png ├─ fonts/ │ ├─ Geist.woff2 │ └─ InstrumentSerif.woff2 ├─ referensi/ ← contoh gaya │ └─ feed-ig.jpg └─ motion/ ← diisi Claude
  1. Buat repo baru di github.com/new (boleh Private), misal otakrental-brand. Untuk jalur lokal, cukup folder biasa.
  2. Upload logo, font (file .woff2/.ttf), dan 2–3 gambar referensi gaya.
  3. Buat file CLAUDE.md dengan isi seperti contoh di bawah. Claude Code otomatis membaca file ini di setiap sesi.
FONTPakai font berlisensi bebas (Google Fonts). Unduh di fonts.google.com → Download family.
# Brand: Otak Rental Warna: krem #FAF7F0 (latar), tinta #05100E (teks), lime #D4E751 (aksen), hijau #17463A. Font: Geist (judul tebal), Geist Mono (label kecil, huruf kapital, spasi lebar), Instrument Serif italic (kata penekanan). Gaya: bersih, grid tipis di latar, crop mark di sudut, stabilo lime di kata kunci. Logo: assets/logo.png (latar terang), assets/logo-putih.png (latar gelap). # Aturan motion - Semua animasi: 1 file HTML di folder motion/, fungsi renderAt(t) + DURATION (deterministik). - Easing ease-out untuk masuk, selalu ada jeda diam ≥1 dtk di akhir. - Teks minimal 80px dari tepi. Cek dengan still frame sebelum render penuh. - Output MP4 H.264 60 fps di motion/out/.

Bab 06 · cloud & lokal sama

Prompt 1:bangun mesin render.

Cukup sekali per repo. Setelah mesin ini ada, setiap video baru tinggal "isi animasinya".

Baca CLAUDE.md. Siapkan mesin render motion di folder motion/: 1. render.mjs (Node): sajikan folder motion/ lewat server lokal, buka halaman animasi di Chromium (Playwright) dengan ukuran --width × --height, lalu untuk setiap frame panggil window.renderAt(t) dan ambil screenshot. Durasi dari window.DURATION. 2. Opsi: --page, --name, --fps 60, --sub 6 (motion blur: rata-rata 6 sub-frame per frame), --stills 1.5,4,9 (hanya simpan PNG di detik tertentu untuk preview). 3. Gabungkan frame dengan ffmpeg: H.264, CRF 18, yuv420p, +faststart, 60 fps. Kalau ada file WAV dengan nama yang sama, masukkan sebagai audio AAC. 4. Buat contoh.html: 5 detik, 1080×1350, teks brand masuk dengan ease-out. 5. Tes: buat 3 still, lalu render penuh ke motion/out/contoh.mp4. Tunjukkan hasilnya. 6. Tulis cara pakainya di motion/README.md. Commit dan push.

--stills

Preview super cepat: hanya beberapa gambar diam. Pakai ini sebelum render penuh supaya hemat waktu & kuota.

--sub 6

Motion blur asli. Makin besar makin halus, tapi render makin lama. 6 sudah cukup.

CRF 18

Kualitas tinggi. Kalau file terlalu besar untuk diunggah, naikkan ke 22–24.

LAMA RENDERVideo 15 detik 60 fps = 900 frame. Dengan motion blur, butuh beberapa menit. Biarkan Claude bekerja; kamu bisa mengerjakan hal lain.

Perintah yang nanti sering kamu lihat

Perintah render · dijalankan oleh Claude
# preview cepat: 3 gambar diam $ node motion/render.mjs --page contoh.html --width 1080 --height 1350 --stills 1,2.5,4.5 # render penuh 60 fps + motion blur $ node motion/render.mjs --page contoh.html --width 1080 --height 1350 --name contoh ✓ 300 frame · contoh.mp4 (1080×1350, 60 fps, 5.0 dtk)

Kamu tidak perlu mengetik perintah ini. Tapi kalau paham artinya, kamu bisa mengecek apa yang sedang dikerjakan Claude.

Prompt 2:brief videonya.

Ini prompt yang kami pakai untuk video contoh "Kopi Nalar". Formatnya seperti brief ke editor manusia: tujuan, format, alur per detik, dan standar kualitas.

Buat contoh motion graphic 15 detik untuk slide 4 carousel "Price List Motion", biar calon klien tahu hasilnya. Buat sekeren dan seprofesional mungkin. Format 1080×1350 (4:5), 60 fps, brand fiktif "Kopi Nalar" (es kopi susu gula aren). Alur: 0–3 dtk Hook "Pagi berat?" jatuh ke layar gelap, huruf memantul. 3–7 dtk Gelas digambar garis demi garis, es jatuh, 3 label rasa muncul bergantian. 7–9,6 dtk Kamera masuk ke gelas, 3 panel bergantian (push-up): Dingin, Manis pas, Nendang. 9,6–11,7 Harga lama Rp18.000 dicoret, Rp12.000 berputar seperti slot, stiker -33%. 11,7–15 Logo jatuh & memantul, tagline, CTA, lalu diam. Bab 08

Still → revisi →render → kirim.

Beginilah satu putaran kerja kami. Kuncinya: jangan render penuh sebelum still-nya benar.

Lembar still (contact sheet) · 6 titik waktu
  1. Still. Claude membuat gambar diam di beberapa detik penting, digabung jadi satu lembar.
  2. Nilai. Cek: teks kepotong? terlalu mepet? warna pas? urutan jelas?
  3. Revisi dengan kalimat spesifik (lihat bab 09).
  4. Render penuh + suara setelah still oke.
  5. Tonton MP4-nya, lalu kirim/upload.

Suara: dibuat, bukan dicari

Semua suara di video kami dibuat oleh skrip Python dari nada dan noise sederhana: whoosh, pop, klik, bass. Karena dibuat sendiri, tidak ada masalah hak cipta, dan setiap efek bisa ditaruh tepat di detik gerakan.

Buat sound_kopi.py (hanya library bawaan Python) yang menghasilkan WAV 15 detik: whoosh saat scene berganti, "pop" saat huruf mendarat, klik slot saat harga berputar, bass hit saat logo jatuh, dan musik latar lembut 100 BPM. Samakan waktunya dengan animasi.
MUSIKLebih suka lagu? Render tanpa suara, lalu tambahkan musik bebas royalti di CapCut atau langsung dari Instagram.
